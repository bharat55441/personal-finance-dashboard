# Personal Finance Dashboard

A personal finance tracker with user accounts. This repository is the frontend: React 19, TypeScript, Vite, Zustand, Recharts, Tailwind CSS v4, React Router, PapaParse and date-fns.

The backend is a separate project, **[pfd-api](../pfd-api)** (Node.js, Express 5, MongoDB). See its README for the API reference and deployment settings.

```
bharat/
  pfd/        ← this app (frontend)
  pfd-api/    ← REST API
```

## Features

- **Accounts**: sign up and sign in. The session is an httpOnly cookie set by the API, and each user only sees their own data.
- **Transactions**: add, edit and delete income or expenses. You can filter by month, type and category, and search notes.
- **Dashboard**: shows your total balance, the month's income, expenses and net savings, a 6-month income vs. expense chart, a category donut chart, and a spending trend you can switch between 6 and 12 months.
- **Budgets**: set a monthly limit per category. Progress bars warn at 80% and show an alert when you go over.
- **Recurring transactions**: generated by the API each month, using your local date.
- **Savings goals**, **CSV import/export**, **dark mode** and **sample data** (Settings → *Load sample data*).
- **Migration**: data saved by the old browser-only version can be uploaded to your account with one click.

## Running locally

```bash
# terminal 1: the API
cd ../pfd-api && npm install && npm run dev    # http://localhost:4000

# terminal 2: this app
npm install && npm run dev                     # http://localhost:5173
```

In development, Vite forwards `/api` to `http://localhost:4000`, so no extra setup is needed.

## Production

Set the API's URL when building:

```bash
VITE_API_URL=https://api.example.com npm run build    # output in dist/
```

Then, on pfd-api, set `CLIENT_ORIGIN` to this app's URL. If the two are on different sites, also set `COOKIE_SAMESITE=none` (this requires HTTPS). See `../pfd-api/README.md`.

## Structure

```
src/
  api/client.ts   fetch wrapper (VITE_API_URL, cookie credentials, ApiError)
  store/          useFinanceStore.ts: API-backed Zustand store (only the theme is persisted locally)
  pages/          Login, Dashboard, Transactions, Recurring, Budgets, Goals, Settings
  components/     UI primitives, Layout, charts/, LocalDataBanner, ErrorToast...
  hooks/ types/
  utils/          csv, finance, recurring, formatCurrency, sampleData (pure functions with tests)
```

`src/utils/recurring.ts` has the same date rules as `pfd-api/src/lib/recurring.ts`. If you change one, change the other.
